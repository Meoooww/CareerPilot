# CareerPilot

[中文](#中文) | [English](#english)

---


CareerPilot 是一个职业规划仓库。
每个分支面向一类人群，沉淀对应的职业规划逻辑与实现方式。

### 当前范围

- 仓库按不同人群拆分为不同分支
- 当前仅实现 `skill-grad`
- 其他分支面向其他人群，暂未实现

### 快速开始

```bash
git clone https://github.com/Meoooww/CareerPilot.git
cd CareerPilot
git checkout skill-grad
```

CareerPilot is a career planning repository.
Each branch is designed for a specific audience and contains the corresponding career planning logic and implementation.

### Scope

- The repository is organized by branches for different audiences
- Only `skill-grad` is currently implemented
- Other branches are intended for other groups and have not been implemented yet

### Quick Start

```bash
git clone https://github.com/Meoooww/CareerPilot.git
cd CareerPilot
git checkout skill-grad
```
